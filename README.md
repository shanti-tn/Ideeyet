# Coopérative Ideeyet

Site de la coopérative Ideeyet : ménage et aide à la personne à Tunis, par une coopérative portée et gouvernée par des travailleuses domestiques.

Bilingue français / derja tunisienne (bouton FR / تونسي en haut de page).

## Fichiers

- `index.html` : le site (une seule page, sans dépendance à installer)
- `illustrations.html` : planche de recherche des illustrations
- `assets/` : illustrations

## Mise en ligne

Le site est publié avec GitHub Pages depuis la branche `main`, dossier racine :
https://shanti-tn.github.io/Ideeyet/

Pour modifier un texte, éditer `index.html` : chaque texte existe en deux versions, `<span class="fr">…</span>` et `<span class="ar">…</span>`.
